# World3 Empirical

**Version:** 0.1

**License:** MIT

An empirical World3 research model combining the system-dynamics engine with observed data, calibration artifacts, backtests, and explicit provenance. The repository contains the model code, source and processed datasets used to construct or calibrate it, retained validation/calibration results, and the scripts required to reproduce those scientific inputs and outputs. It is maintained as a model core without an end-user interface.
