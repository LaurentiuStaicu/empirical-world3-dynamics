# Empirical World3 Dynamics v0.1.0

**Scientific-core baseline — initial research release**

EWD v0.1.0 is the first formal public snapshot after consolidation around the scientific model core.

## Included

- World3 reference/scenario engine;
- observed datasets used by the scientific core;
- calibration, backtest and validation artifacts;
- BAU Hybrid 2026 retained results and provenance;
- scientific input manifests and reproducibility scripts;
- conservative extension interfaces and promotion gates.

The previous end-user interface is intentionally not included.

## Scientific status

The retained BAU Hybrid 2026 model is explicitly an **experimental scenario model, not a probabilistic forecast**.

Structural selection is frozen through 2018. The displayed production trajectory is subsequently refitted using observations through 2025, so it is not itself an independent holdout forecast. The P10-P90 envelope is pointwise sensitivity across accepted candidates and must not be interpreted as a calibrated probability interval.

Several structural parameters remain weakly identified. EROI, climate-water, minerals and AI are not coupled into the central run. Candidate extension mechanisms remain inactive unless the declared S1-S10 scientific promotion gates are satisfied.

See `STATUS.md` for the maintained scientific boundary and `CITATION.cff` for citation metadata.

## Versioning
